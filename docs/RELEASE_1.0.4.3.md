# SnapMatch 1.0.4.3

Обновление надёжности и безопасности SnapMatch.

## Что изменилось

- MCP-инструменты повторно проверяются перед вызовом. Неизвестные, неоднозначные и изменяющие данные вызовы блокируются без подтверждения.
- Сообщения одного пользователя обрабатываются последовательно; исправлены повторная постановка в очередь и резервирование слота модели.
- Исправлена защита от повторной отправки ответов «секретаря» и освобождение блокировки после ошибки.
- Настройки записываются атомарно с резервной копией. Обработка ключей и журналирование стали безопаснее.
- Голосовые сообщения можно распознавать через OpenAI, Groq и совместимый API без Vosk и FFmpeg. Локальный Vosk вынесен в отдельный сценарий сборки.
- Windows-установщик обновлён до версии 1.0.4.3; при обновлении сохраняется прежний AppId.

## Загрузки

- `SnapMatch_Setup_v1.0.4.3.exe` — обычный Windows-установщик.
- `SnapMatch_1.0.4.3_amd64.deb` — пакет для Debian/Ubuntu, собранный в GitHub Actions.

Vosk-установщик не приложен: локальная модель распознавания отсутствует в этой сборке. Для режима Vosk нужны отдельная сборка, модель и FFmpeg.

Linux-пакет собирается автоматически; установка и запуск GUI на отдельной Debian/Ubuntu-машине пока не проверялись.
