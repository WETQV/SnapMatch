# Changelog

Формат: новые версии сверху. Подробности о 1.0.4.3 - в [docs/RELEASE_1.0.4.3.md](docs/RELEASE_1.0.4.3.md).

## 1.0.4.4

Обновление интерфейса, производительности и поддержки Linux.

### Что нового

- **Новый загрузочный экран**: карточка с анимированным фоном и кольцом прогресса, реальные статусы запуска. Главное окно собирается, пока экран на виду, и больше не ждёт фиксированные ~6 секунд.
- **Вкладка «Расшифровки»**: история расшифровок голосовых сообщений и кружочков (таблица `voice_transcriptions`, запись из обработчика сообщений).
- **MCP в фоне**: проверка (discover), запуск и остановка серверов больше не подвешивают окно.
- Кнопки автоматически подгоняются по ширине под текст.

### Производительность

- Индексы таблицы `messages`; пересчёт токенов при обрезке контекста за O(1) на сообщение.
- Регулярные выражения при потоковом ответе выполняются не на каждый фрагмент, а по интервалу.
- LRU-кэш data URL картинок; таблицы пользователей и групп не пересоздаются без изменений.
- Таймеры вкладок работают только когда вкладка видна; журнал ограничен 3000 записями; устранён N+1 во вкладке «Секретарь».

### Промпты

- История и шаблоны системного промпта пишутся атомарно; повреждённый JSON откладывается в `*.corrupt-<время>`, а не затирается.
- Кэш в `get_settings`, одно-проходная подстановка плейсхолдеров.

### Linux

- Каталог данных: портативный режим, если рядом лежит `config.json`, иначе `~/.local/share/snapmatch`.
- Блокировка единственного экземпляра в `XDG_RUNTIME_DIR`; открытие файлов через `QDesktopServices`.
- Остановка MCP-серверов по группе процессов; корректная обработка SIGINT/SIGTERM.
- Системный моноширинный шрифт, запасные шрифты для символов и эмодзи, PNG-иконка приоритетнее ICO, подсказки по установке FFmpeg, иконка в `snapmatch.spec` по платформе.

### Известные ограничения

- Перезапуск бота по-прежнему блокирует интерфейс на 15-30 секунд.
- `QThread.terminate()` остаётся аварийным вариантом остановки.
- Остановка MCP и обработка сигналов на Linux проверены только частично.
- Каталог `tools/ui_mockup/` содержит макет будущей темы и не подключён к приложению.

### Файлы релиза

- `SnapMatch_Setup_v1.0.4.4.exe` - Windows-установщик (собирается вручную через `build.bat`).
- `SnapMatch_1.0.4.4_amd64.deb` - пакет для Debian/Ubuntu.
