# Changelog

Формат: новые версии сверху. Подробности о 1.0.4.3 - в [docs/RELEASE_1.0.4.3.md](docs/RELEASE_1.0.4.3.md).

## 1.0.5.0

Новый интерфейс, статистика и обновления зависимостей. Включает всё из 1.0.4.4 (загрузочный экран, вкладка «Расшифровки», оптимизации, поддержка Linux).

### Интерфейс

- Новая оболочка: боковая навигация с логотипом, собственная рамка окна (на Linux по умолчанию), заголовок с названием страницы.
- Темы: системная, тёмная, светлая, OLED; системный или свой акцентный цвет; анимации можно отключить. Настройки в «Доп. настройки», «Оформление».
- Все вкладки перенесены на новый дизайн: Пользователи, Настройки, Голос, Расшифровки, Доп. настройки, MCP, Секретарь.
- Собственные окна вместо стандартных диалогов (вопрос, предупреждение, ввод, выбор цвета) и собственные подсказки при наведении.
- Разделы настроек сворачиваются без дёрганья прокрутки; плитки инструментов MCP; журнал с перекраской при смене темы.

### Статистика

- В окне «Статистика»: блок «Звук» (голосовые, кружки, ошибки, длительность, движки), «Чем пользовались» (топ MCP-инструментов, события секретаря, режимы сообщений) и «Токены по моделям».
- Новая таблица `token_usage` с колонкой `model_id` (NULL для старых записей, миграция безопасная).

### Модели и голос

- Чат-модель по умолчанию: `gpt-5.6-terra`. Недоступные модели OpenAI (отключённые или отсутствующие в `/models`) автоматически заменяются; Groq и custom не трогаются.
- STT OpenAI: по умолчанию `gpt-transcribe`, список моделей подтягивается из `/models` с кэшем на 24 часа; устаревшие `whisper-1` и `gpt-4o-*-transcribe` помечаются (отключение 26.02.2027).
- Vosk необязателен: понятная ошибка и подсказка, `requirements-local-stt.txt`.

### Сборка и зависимости

- Границы версий в `requirements.txt`; `openai` и `mistune` убраны (не использовались); PyInstaller вынесен в `requirements-build.txt`.
- `snapmatch.spec`: onefile на Linux меньше примерно на 12,5 МБ (96,8 до 84,3 МБ).
- Windows-установщик: светлая и тёмная тема (следует за Windows), брендовые картинки мастера, Inno Setup 6.6+.
- Иконка приложения набором размеров, SVG и `.desktop` для Linux.

## 1.0.4.4

Обновление интерфейса, производительности и поддержки Linux.

### Что нового

- **Новый загрузочный экран**: карточка с анимированным фоном и кольцом прогресса, реальные статусы запуска. Главное окно собирается, пока экран на виду, и больше не ждёт фиксированные ~6 секунд.
- **Вкладка «Расшифровки»**: история расшифровок голосовых сообщений и кружочков (таблица `voice_transcriptions`, запись из обработчика сообщений).
- **MCP в фоне**: проверка (discover), запуск и остановка серверов больше не подвешивают окно.
- Кнопки автоматически подгоняются по ширине под текст.

### Производительность

- Индексы таблицы `messages`; пересчёт токенов при обрезке контекста за O(1) на сообщение.
- Регулярные выражения при потоковом ответе выполняются не на каждый фрагмент, а по интервалу.
- LRU-кэш data URL картинок; таблицы пользователей и групп не пересоздаются без изменений.
- Таймеры вкладок работают только когда вкладка видна; журнал ограничен 3000 записями; устранён N+1 во вкладке «Секретарь».

### Промпты

- История и шаблоны системного промпта пишутся атомарно; повреждённый JSON откладывается в `*.corrupt-<время>`, а не затирается.
- Кэш в `get_settings`, одно-проходная подстановка плейсхолдеров.

### Linux

- Каталог данных: портативный режим, если рядом лежит `config.json`, иначе `~/.local/share/snapmatch`.
- Блокировка единственного экземпляра в `XDG_RUNTIME_DIR`; открытие файлов через `QDesktopServices`.
- Остановка MCP-серверов по группе процессов; корректная обработка SIGINT/SIGTERM.
- Системный моноширинный шрифт, запасные шрифты для символов и эмодзи, PNG-иконка приоритетнее ICO, подсказки по установке FFmpeg, иконка в `snapmatch.spec` по платформе.

### Исправления интерфейса

- «Голос»: добавлена кнопка «Как установить FFmpeg»; при смене движка STT введённые, но ещё не сохранённые ключ и модель не теряются.
- «Секретарь»: подтверждение удаления владельца; сохранение профиля больше не сбрасывает форму переопределений чата; некорректные числа вызывают предупреждение вместо тихой подмены значением по умолчанию.
- MCP: подтверждение удаления сервера и перезаписи примера; невалидный Access JSON не затирается при переключении флажков; убрано ложное обещание маскировки секретов в подсказке env; фильтр с задержкой 200 мс; убраны повторные обновления аудита.
- «Доп. настройки»: подпункты Rich отключаются вместе с «Rich Messages»; окно контекста меньше 1024 или не число не сохраняется молча, а показывает предупреждение; ошибки сохранения показываются в окне.
- Редактор промпта: удаляется только выбранный шаблон (а не все с таким именем); мусорные записи шаблонов пропускаются; сравнение несохранённого текста корректно; убран скрытый элемент placeholders_help.

### Известные ограничения

- Перезапуск бота по-прежнему блокирует интерфейс на 15-30 секунд.
- `QThread.terminate()` остаётся аварийным вариантом остановки.
- Остановка MCP и обработка сигналов на Linux проверены только частично.
- Каталог `tools/ui_mockup/` содержит макет будущей темы и не подключён к приложению.

### Файлы релиза

- `SnapMatch_Setup_v1.0.4.4.exe` - Windows-установщик (собирается вручную через `build.bat`).
- `SnapMatch_1.0.4.4_amd64.deb` - пакет для Debian/Ubuntu.
